## 🚀OVERVIEW
DFD Folder Automation is a lightweight Vite-based web application that demonstrates how to use the Dropbox API to save a file directly into your Dropbox account using an access token.

## ✅PREREQUISITES
- Node.js v14+ and npm (or yarn)
- A Dropbox API app with an access token
- JavaScript, HTML, and CSS

## 📥INSTALLATION
####  Clone the repository
```bash
git clone https://github.com/your-org/dfd-dropbox-uploader.git
cd dfd-dropbox-uploader
```

#### Install dependencies
```bash
 npm install
 npm install dropbox
 ```

#### Configure your Dropbox access token
```
 Open src/main.js and replace the ACCESS_TOKEN with your own.
 ```
